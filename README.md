What is Ente Photos?

Ente Photos is an end-to-end encrypted photo backup app, a private alternative to Google Photos and iCloud. Everything is encrypted on your device before it leaves it. The server only ever sees encrypted data, so not even Ente's own team can see your photos.

It's fully open source (client and server), independently audited by three security firms, and available on every major platform.
